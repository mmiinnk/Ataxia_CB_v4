# 开展筛选具有共性时空发育病理特征的共济失调基因集群研究

共济失调是一组在临床与遗传上高度异质的神经系统疾病，其致病基因涉及多种分子机制、遗传方式与发病年龄，病理改变亦各不相同。为回答这些异质性病因之间是否存在共性的发育病理特征，本阶段首先系统构建了临床共济失调致病基因的注释体系。我们通过检索GeneReviews、OMIM与PanelApp等权威文献和数据库，逐病种确定了每一种共济失调亚型所对应的致病基因，并同步整理其突变类型、遗传方式、发病年龄、病程特征、主要病理改变与分子机制归属；所有条目均经独立人工复核，分歧条目由第二名复核者仲裁后定稿。最终形成的注释体系涵盖177个基因、188条基因与疾病的对应关系，覆盖186个临床亚型，其中证据充分的核心致病基因108个（含ATXN8OS一个非编码RNA基因，SCA8的CTG·CAG重复扩增位于ATXN8OS与ATXN8两个重叠转录本之间，按既定规则不参与表达谱统计，故后续分析实际涉及107个基因）、扩展层54个、外周层15个，外周层基因不参与后续统计。这一体系较为完整地呈现了共济失调的临床异质性：按分子机制可分为8类，按遗传方式分为常染色体隐性（60个）、常染色体显性（41个）与X连锁（7个），按发病年龄分为成年起病（34个）、先天起病（31个）、儿童起病（26个）与青少年起病（17个），突变类型有7种，病程特征有5种，主要病理改变多达24种，临床上可归纳为显性脊髓小脑性共济失调、隐性共济失调、先天性发育异常、代谢与可治疗类型等8个分组。这种在多个维度上同时存在的异质性，使得“是否存在跨病因的共性发育特征”成为一个值得系统检验的问题，也为按机制类别与发病年龄分层比较提供了明确的分组依据。

在此基础上，我们分别利用小鼠与人的小脑单核转录组数据，构建了上述致病基因在发育过程中的表达图谱。小鼠数据包含24个供体的115,282个细胞核，覆盖自胚胎E10.5至成年9周龄共12个发育分期；人源数据包含27个供体的180,956个细胞核，覆盖自Carnegie18期至成年共13个发育分期。两个物种的细胞类型按同一套注释规则划分，包括浦肯野细胞、颗粒细胞谱系、深部核团神经元、中间神经元、少突胶质谱系、星形胶质细胞、祖细胞与免疫细胞共8个主要类群，另设单刷状细胞与全小脑两个参照类群，其中免疫细胞在小脑实质内以小胶质细胞为主。我们逐一计算了每个细胞类群在每个发育分期的平均表达水平；细胞数过少的组合不作估计而直接记为缺失，既不插值也不以零替代，小鼠120个组合中有92个、人源130个组合中有88个满足分析要求。为确保图谱可靠，我们对各数据集的细胞规模、各细胞类群的细胞数、归一化前后的一致性、经典细胞类型标记基因的归属，以及三个已知发育方向基因的变化趋势逐一作了核对，结果均与既往报道一致。

在小鼠中，进入统计的107个基因有101个可以检出，其余6个（ATN1、CA8、KIAA0586、PDYN、SAMD9L与TCTN2）不在该数据集的基因列表中。以Spearman秩相关检验各基因在每个细胞类群中随发育的变化，并经Benjamini–Hochberg法控制假阳性后，在107个基因与10个细胞类群（8个主要类群，另加单刷状细胞与全小脑两个参照类群）构成的1070个组合中，共识别出136个具有显著发育趋势的组合，其中ITPR1在浦肯野细胞中随发育上升、MBP在少突胶质谱系中上升、ATOH1在颗粒细胞谱系中下降，均与已知的发育规律相符。进一步把这1070个组合按时序形态归为七类：发育后期持续升高的93个、单调上升的79个、单调下降的51个、仅在某一时间段升高的35个、呈瞬时峰值的10个；另有727个组合因变化趋势未达显著、形态亦不符合上述任一类型而归为无显著时序模式，这些组合的变化幅度中位数约为0.37，只是未通过显著性检验，不宜理解为表达恒定；余下75个组合记为缺失，其中60个来自6个在小鼠数据中无法检出的基因（每个基因涉及全部10个类群），15个因表达过低、峰值不可信而被掩膜。在细胞类型归属上，有6个基因表现出明确的类群特异性：ITPR1、DAB1与PRKCG特异于浦肯野细胞，RELN特异于颗粒细胞谱系，SLC1A3特异于星形胶质细胞，CYP27A1特异于少突胶质谱系，特异性指数介于0.865至0.954之间。此外，我们还给出了每个基因首次达到类群主导表达的发育分期，以及其表达高峰所处的时期。

在细胞类型这一层面寻找共性时，结果却提示共性可能并不在此。101个可检出的基因中有87个在多个细胞类群中广泛表达，并不专属于任何一类细胞；以分子机制类别与“细胞类群×发育时期”的组合进行置换富集检验，也未发现达到显著的富集。在两个物种中均达到显著的结果只有一项：离子通道与突触类基因中表现为“表达平稳”的数目明显少于随机期望，小鼠只有5个而随机期望约11个（富集倍数log2FE=−1.11，q=0.021），人源只有2个而期望约12个（log2FE=−2.31，q=0.0042），也就是说，这一类基因几乎都在发育过程中发生真实的表达变化，很少维持恒定。这一结果与病理注释是一致的：进入分析的107个基因所对应的亚型中，61个以小脑萎缩为主要病理改变，17个明确记录有浦肯野细胞丢失，说明神经元仍是最主要的受累靶点，而致病基因之所以呈广谱表达，可能反映的是发育程序的普遍参与而非某一群细胞的专属损伤。若以每个基因表达占比最高的细胞类群来计，其在各类群间的分布相当均匀：人源107个基因中，免疫细胞27个、星形胶质细胞17个、祖细胞13个、颗粒细胞谱系12个、浦肯野细胞11个、中间神经元10个、深部核团9个、少突胶质谱系8个；小鼠101个可检出基因中，免疫细胞19个、星形胶质细胞17个、深部核团14个、浦肯野细胞13个、中间神经元与颗粒细胞谱系各12个、少突胶质谱系9个、祖细胞5个；峰值落在免疫细胞即小胶质细胞的基因虽略多，但这些基因绝大多数仍属广谱表达，其特异性指数约0.42、峰值占比约0.20，与全表中位水平相当，因此并不构成真正的小胶质细胞偏好，其中只有SAMD9L在人源数据中表现出明确的小胶质细胞特异性，特异性指数达0.938。不过机制类别的分布提供了一个值得进一步检验的线索：人源数据中峰值落在小胶质细胞的基因以线粒体代谢类（9个）与DNA修复类（8个）为主，10个核心DNA修复类致病基因中有8个（APTX、ATM、MRE11、PNKP、RFC1、SETX、TDP2与XRCC1）的相对表达占比以小胶质细胞为最高，而在两个物种中峰值一致落在小胶质细胞的10个基因里，有7个的跨物种保真度评分达到满分；考虑到DNA修复缺陷类共济失调（如A-T）本身常伴免疫异常与肿瘤易感，这一分布是否提示小胶质细胞参与其中，有待在疾病数据中检验。就发育时序而言，人源小胶质细胞中107个致病基因的表达高峰以胎儿期最多（40个），其后依次为婴儿期24个、胚胎期22个与成年期21个，分布相对分散，并未集中于某一特定时期；而小鼠的小胶质细胞仅在胚胎早期至出生后早期（E10.5至P7）达到细胞数要求，其峰值分布受覆盖范围限制，不足以判断早晚。

既然共性不主要体现在细胞类型上，我们转而比较不同机制类别在发育时间轴上的位置。由于人与小鼠的发育分期无法按年龄直接对应，我们以人的分期为参照，将小鼠各分期依据已发表的组织学对应关系换算到同一发育次序上，再考察每个基因表达高峰出现的早晚。结果显示，不同分子机制类别之间的高峰时序差异十分显著（Kruskal–Wallis检验p=1.3×10⁻³）：DNA修复类基因的高峰出现得最早，10个基因中有6个落在最早的胚胎分期；离子通道与突触类以及细胞骨架与运输类最晚，前者17个基因中有12个、后者11个基因中有7个的高峰落在出生后至成年阶段；纤毛与先天发育类、线粒体代谢类、蛋白稳态与RNA代谢类以及polyQ类居于两者之间，其高峰位置的中位数落在胚胎晚期（约相当于人胎17至18周），但各类内部分布较为分散，例如线粒体代谢类23个基因中仍有10个的高峰出现在最早的胚胎分期。类别间的两两比较有4对达到显著（q<0.05），效应量均属大效应（Cliff's delta为0.52至0.76），其中离子通道与突触类、细胞骨架与运输类晚于DNA修复类的效应量均达0.76。据此，致病基因大致可划分为两个具有共性发育特征的集群：一是以DNA修复类为代表的“早期程序群”，其表达程序在胚胎期即已基本完成；二是以离子通道与突触类、细胞骨架与运输类为代表的“晚期成熟群”，其表达高峰出现在出生后的环路成熟期；其余各类介于两者之间。晚期成熟群中表现最突出的是GRM1，即代谢型谷氨酸受体1，其突变分别导致常染色体隐性的SCAR13与显性的SCA44：在小鼠中，它在6个细胞类群均呈显著单调上升（浦肯野细胞ρ=+0.964、颗粒细胞谱系ρ=+0.972、深部核团神经元ρ=+0.883、中间神经元ρ=+0.825、祖细胞ρ=+0.832、全小脑ρ=+0.944，q值均小于0.05），在人源数据中同样有5个类群显著上升（相关系数介于0.80与0.98之间，仅祖细胞类群在两物种间方向不一致），其表达高峰接近整个发育序列的末端，在小鼠为成年期，在人源为婴儿期的3岁（13个分期中仅晚于成年）；在浦肯野细胞与颗粒细胞谱系中，人与小鼠的表达轨迹形状相关性分别高达0.991与0.986，综合保真度评分0.714，属高证据等级，提示GRM1的功能异常更可能体现在出生后至成年阶段的谷氨酸能信号传递中。与之形成对照的是SCA3（Machado-Joseph病）的致病基因ATXN3：它虽同属polyQ机制类，正常表达程序却相反，表现为胚胎期最高、出生后逐步下降（小鼠全小脑ρ=−0.762，q=0.022；颗粒细胞谱系ρ=−0.699，q=0.032；人源全小脑ρ=−0.703，q=0.034），在两物种均可判定的4个细胞类群中变化方向完全一致，其中浦肯野细胞、颗粒细胞谱系与中间神经元为下降，星形胶质细胞为小幅上升，其表达高峰出现在胚胎中期，约当小鼠E12.5前后。考虑到SCA3在临床上表现为成年起病（平均约40岁）、病程进行性、主要病理改变为齿状核神经元丢失，发育表达窗与发病窗之间相隔数十年，这一对照提示ATXN3的毒性作用可能更多发生在表达程序完成之后的长期维持阶段，而非发育期本身。总体而言，这一时序层级为理解共济失调的共性机制提供了一种可能的解释：多数致病基因在胚胎期已完成表达程序，其功能后果可能要等到出生后神经环路成熟时才逐渐显现，这与“发育程序失调病”的假说相符，也提示按发育窗口分层寻找干预靶点或许是可行的思路。

为使上述结果不局限于单一物种，我们在人源数据上完成了同一套分析，并系统比较了两个物种之间的保守程度。人源数据中这107个基因全部可以检出，共识别出185个具有显著发育趋势的组合。为使发育阶段具有可比性，我们没有采用年龄换算，而是以两物种共有的26个细胞分化状态作为共同的比较轴。结果显示，两物种的发育变化方向一致率为70.0%，表达轨迹形状的相关中位数为+0.563；按四项指标加权的保真度评分中，76个基因达到高证据等级，其中细胞骨架与运输类基因的保守性最高（评分中位数0.989），离子通道与突触类次之（0.792），蛋白稳态与RNA代谢类最低（0.292）。将基因层面的结果汇总到疾病层面后，我们进一步得到了覆盖117个疾病条目的保真度评分，可用于评估各类共济失调的小鼠模型在多大程度上能够反映人类疾病的发育特征，从而为动物模型的选择与临床转化的可行性判断提供量化参考。人源结果与小鼠结果方向一致，支持前述发育时序层级在两个物种间具有相当的稳健性。

下一阶段的工作将围绕疾病数据展开。我们已完成对多个公开疾病队列的盘点，包括SCA1、A-T与SCA7等，下一步将把这些数据投影到本图谱所建立的正常发育参照之上，识别跨病因的共享扰动节点与网络；同时补齐BrainSpan、GTEx与模型鼠差异表达签名等外部数据，在独立数据集中验证图谱的主要结论，并完成基因注释的来源逐条核实与第二轮独立标注。上述工作完成后，本图谱将形成完整的跨物种发育参照体系，其统计结果与图表亦可直接用于论文撰写。
